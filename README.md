# 온리뷰(onlyview) 유지보수 — 1차 분리본

## 이번 변경
- `index.html`에서 공통 변환 함수 6개를 `js/utils/formatters.js`로 분리했습니다.
- 기존 HTML 화면과 함수 구현은 유지하고, 기존 JavaScript 모듈에서 상대 경로 import로 불러오도록 연결했습니다.
- `app.py`는 변경하지 않고 원본을 보존했습니다.

## GitHub Pages 적용 시 주의
- `index.html`과 `js/` 폴더는 같은 저장소 루트에 두어야 합니다.
- `app.py`는 GitHub Pages에서 실행되지 않습니다. `/parse` 기능을 사용하려면 별도 Python 서버 배포가 필요합니다.
- 기존 HTML이 참조하는 `체험단_정산_리포트_양식.xlsx` 파일은 이번 업로드 자료에 포함되지 않았습니다. 기존 저장소에 해당 파일이 있다면 그 위치와 파일명을 그대로 유지하세요.
- Firebase 설정과 데이터베이스 보안 규칙은 이번 작업에서 변경하지 않았습니다.

## 1차 검증
- 기존 인라인 모듈 스크립트의 JavaScript 구문 검사: 통과.
- 변경 후 인라인 모듈 스크립트의 JavaScript 구문 검사: 별도 수행 필요.
- 유틸리티 모듈의 구문 검사 및 테스트: 별도 수행 필요.
- Firebase 로그인, Firestore CRUD, 화면 렌더링, 엑셀 다운로드, 외부 URL 파싱: 브라우저/실제 서버에서 아직 검증하지 않음.
